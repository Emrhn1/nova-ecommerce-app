# Project Guidelines & Collaboration Rules

## Core Collaboration Principles

1. **Önce Anlat, Sonra Yaz (Discuss First, Then Code):**
   - Before implementing any page, component, or feature, present a detailed plan including render strategy (ISR, SSR, SSG, PPR, CSR), caching rules, DB impact, and SEO considerations.
   - Wait for discussion, question-and-answer, and approval from the user before writing the code.

2. **Bana Açıkla Refleksi (Explain All Code Decisions):**
   - Whenever code is written or modified, be ready to thoroughly explain choices (e.g. middleware matcher, revalidation times, state management, dynamic vs static splits).

3. **Architecture Decisions Log (`docs/architecture-decisions.md`):**
   - Maintain and update [architecture-decisions.md](file:///c:/Users/Emirhan/WebstormProjects/e-commerce-app/e-commerce/docs/architecture-decisions.md) whenever an architectural decision is made.
   - Record the feature/page, chosen strategy, reasoning, and alternatives considered.
